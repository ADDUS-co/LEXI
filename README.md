# LEXI

**One day. One word. A little more knowledge.**

Персональный английский словарь: одно слово в день из выбранных интересов. Редактируемый MVP на Flask, HTML, CSS и JavaScript — без сборки и платного API. Аккаунты хранятся в SQLite локально или PostgreSQL на сервере.

**Начинаете программировать? Откройте [NOTES_FOR_ADA.md](NOTES_FOR_ADA.md).** Там пошагово объяснены запуск, изменение слов, коллекций, дизайна и публикация.

## Возможности

- Обязательная регистрация перед доступом: email, логин и пароль; вход по email или логину.
- Нейтральный стартовый экран с полупрозрачными словами, медленно движущимися вниз под 60°. Пауза и поддержка reduced motion.
- Фото профиля (JPG, PNG, WebP) с предпросмотром, заменой и удалением.
- Синхронизация избранного, истории, интересов, темы, времени обновления и скрытых карточек между устройствами.
- Девять коллекций и 54 статические учебные записи. Новые коллекции появляются из JSON автоматически.
- Первое знакомство с выбором нескольких интересов; изменить их можно в Collections.
- Ежедневное слово, расширенное объяснение, примеры и различия синонимов.
- For IELTS, Science & Nature, Psychology и Arts & Culture вместе с пятью исходными коллекциями.
- Выбор времени обновления при первом запуске и в Settings, по часовому поясу устройства.
- Карточка для запоминания: двойное нажатие скрывает слово; правильный ввод или еще одно двойное нажатие раскрывают его. Положение сохраняется после закрытия браузера.
- Noir, Studio и Experimental. Смена оформления не меняет слово.
- Saved с удалением и счетчиком; History содержит только просмотренные слова и даты.
- Поиск по Saved/History, произношение средствами браузера, отправка ссылки или копирование.
- Уменьшение движения, экспорт локальных данных, сброс с подтверждением.
- Адаптивность, клавиатурная навигация и локальные лицензированные шрифты.
- PWA-манифест и offline-кеш после первого успешного онлайн-открытия.
- Четыре контакта в подвале из одного файла.

При первом посещении открывается регистрация; существующий аккаунт входит через **Sign in**. До входа разделы сайта и API словаря закрыты. При действующей сессии сайт открывается автоматически. После входа прогресс синхронизируется с базой; локальная копия позволяет продолжать офлайн и отправляет изменения после восстановления соединения. При регистрации можно перенести гостевые данные. Старые гостевые данные не удаляются и при желании переносятся в аккаунт. После выхода стартовый экран снова закрывает доступ, в том числе офлайн. Экспорт сохраняет JSON для личного архива; загрузка произвольного экспортного JSON не предусмотрена. При первом открытии офлайн словарь еще недоступен. Произношение зависит от голосов устройства.

## Windows / VS Code

Нужен Python **3.12 или новее**. Распакуйте ZIP, откройте папку с `app.py` в VS Code и выберите **Terminal → New Terminal**.

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

Откройте `http://localhost:5000`. Остановка: **Ctrl+C**. Активировать среду необязательно: команды используют ее Python напрямую, без изменения PowerShell ExecutionPolicy.

На macOS / Linux:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app.py
```

VS Code Go Live не запускает Flask и API.

## Проверки

Windows:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -p "test_*.py" -v
```

macOS / Linux:

```sh
.venv/bin/python -m unittest discover -s tests -p 'test_*.py' -v
```

Для отдельной проверки интерфейса `tests/browser_smoke.py` дополнительно установите Playwright и Chromium. Они не нужны сайту или Render:

```sh
python -m pip install playwright
python -m playwright install chromium
python tests/browser_smoke.py
python tests/browser_v2.py
python tests/browser_accounts.py
```

Сайт должен быть запущен в другом терминале. Браузерные проверки создают синтетические аккаунты: используйте отдельную тестовую базу через `DATABASE_URL`, без реальных пользователей. Необязательные настройки: `LEXI_TEST_URL`, `CHROMIUM_PATH`. Скриншоты сохраняются в игнорируемую папку `test-results/`.

Стартовый экран оформлен в `static/css/entry.css`; фоновые слова заданы в `templates/index.html`. Контейнер `word-plane` повернут на 60°, а строки двигаются медленно вдоль него. **Pause background** останавливает движение; reduced motion отключает его автоматически.

Сборки JavaScript нет: сохраните файл и обновите страницу. JSON перечитывается при запросе API. После изменения Python перезапустите сервер. Service Worker сначала обращается к сети, а при отсутствии соединения использует кеш; при изменении схемы кеша увеличьте версию в `static/sw.js`.

## Ежедневный выбор

Сайт использует **часовой пояс устройства**. Время выбирается при первом запуске и в **Settings → Your daily rhythm**. Новым пользователям предлагается 08:00; существующим пользователям без настройки сохраняется прежнее время 00:00. До выбранной границы показывается слово предыдущего учебного дня. История при этом записывает реальную дату просмотра.

Проверка выполняется каждые 30 секунд и при возвращении на вкладку. В закрытом браузере код не выполняется: при следующем открытии сразу применяется актуальное расписание. Фоновые уведомления не отправляются. При переводе часов вперед отсутствующее время переносится на первую существующую минуту; при повторе часа используется первое наступление выбранного времени.

Для повтора дважды нажмите на слово или выберите **Test my memory**. На обороте введите полное слово и нажмите **Check my word** либо дважды нажмите на карточку. С клавиатуры можно дважды активировать **Press twice to reveal**. Ошибка ввода не раскрывает ответ. Скрытое слово маскируется также в Saved/History; состояние сохраняется в этом браузере и синхронизируется после входа. Это учебный прием, а не защита публичной базы данных от просмотра исходников.

Коллекции берутся в порядке `collections.json`. Их слова чередуются в порядке `words.json`: первое из каждой коллекции, второе из каждой и так далее. Исчерпанные коллекции пропускаются. Индекс — число календарных дней с **2025-01-01** по модулю длины списка. До конца списка слова не повторяются; затем начинается новый круг.

Изменение интересов может показать ранее встречавшееся слово. Добавление и перестановка записей меняют календарь. Подробности и перенос на Kotlin: [docs/SELECTION.md](docs/SELECTION.md).

For IELTS — учебная подборка академической лексики, не официальный материал IELTS и не обещание экзаменационного балла.

Данные — статические учебные формулировки и примеры со ссылками для дополнительного чтения. Определения не генерируются при запуске. Юридические примеры объясняют язык и не заменяют консультацию по праву конкретной страны. Для учебного курса рекомендуется дополнительная редактура преподавателем.

## Аккаунты и база данных

На стартовом экране выберите **Create account**: email, логин (3–30 латинских букв, цифр или `_`) и пароль (10–128 символов). Вход работает по email или логину без учета регистра. Пароли хранятся как scrypt-хеши; сессия — в HttpOnly cookie на 7 дней, с CSRF-проверкой изменений и ограничением попыток входа. Подтверждение email и восстановление пароля пока не подключены: почтовый сервис не используется.

В профиле **Choose photo → Save photo**: до 5 MB и 16 мегапикселей. Сервер проверяет содержимое, уменьшает изображение до 384 px, удаляет метаданные и хранит результат в базе. Фотография доступна только вошедшему владельцу.

Локально таблицы создаются автоматически в `instance/lexi.sqlite3`, ключ сессии — в `instance/.session-key`. **Сохраните эту папку для продолжения локального использования; не загружайте ее в GitHub и не включайте в общий ZIP.** Смена ключа завершит старые сессии. Пароль и данные соединения никогда не добавляйте в исходники. `.env.example` — пример; Flask сам его не загружает.

Синхронизация отправляет изменения после действий пользователя. Другое устройство получает их при открытии или возвращении во вкладку. При одновременном редактировании версии проверяются сервером: независимые изменения избранного и истории объединяются, удаления учитываются. Для одного одновременно измененного параметра применяется последнее синхронизированное изменение. Часовой пояс остается часовым поясом устройства. Перед выходом приложение дожидается отправки прогресса. Сброс данных внутри аккаунта сбрасывает учебные данные на всех устройствах после синхронизации, сохраняя профиль и фото.

Подробности API и резервного копирования: [docs/ACCOUNTS.md](docs/ACCOUNTS.md).

## Render

1. Отправьте исходники в GitHub без `.env`, `.venv` и `instance/`.
2. В Render выберите **New → Blueprint** и подключите репозиторий с `render.yaml`.
3. Конфигурация связывает Python Web Service с PostgreSQL (`DATABASE_URL`), генерирует постоянный `SECRET_KEY` и включает HTTPS cookie. Перед созданием проверьте условия выбранных планов, срок хранения базы и резервное копирование: бесплатные базы могут иметь ограниченный срок жизни.
4. При ручной настройке создайте PostgreSQL, задайте его Internal Database URL как `DATABASE_URL` и постоянный случайный `SECRET_KEY` в Environment. Добавьте `LEXI_COOKIE_SECURE=1`, `LEXI_TRUST_PROXY=1` и `LEXI_TIMEZONE=Asia/Bishkek`.
5. Build: `pip install -r requirements.txt`. Start: `gunicorn app:app --bind 0.0.0.0:$PORT --workers 2 --timeout 60`. Health Check: `/health`.
6. После деплоя проверьте регистрацию, выход/повторный вход, фото и сохраненные слова со второго устройства.

На Render нужна постоянная PostgreSQL: SQLite на временном диске сервиса потеряет аккаунты при пересоздании сервера. Фото находятся в той же базе, отдельный файловый диск не нужен. Для существующего сервиса также задайте новые переменные перед обновлением версии. Наличие `render.yaml` само по себе не меняет уже созданный вручную сервис.

Gunicorn используется в Linux на Render; для Windows достаточно `python app.py`. Debugger выключен. HTTPS предоставляет Render. Бесплатный Web Service может засыпать. Автодеплой обновляет сайт после отправки изменений в подключенную ветку GitHub; ZIP и локальный запуск сами сайт не публикуют.

## PWA и Android

Установка сайта на домашний экран — PWA, а не нативный Android-виджет. Для виджета нужен отдельный Kotlin-проект с Jetpack Glance после проверки веб-MVP. JSON и алгоритм подготовлены для переноса: `docs/SELECTION.md`.
