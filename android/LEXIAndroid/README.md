# LEXI для Android — открыть готовый сайт в приложении

Здесь готовый Kotlin-проект. Он открывает **https://lexi-m388.onrender.com/#home** внутри Android через WebView. Дизайн, слова, темы, карточки и инструктаж берутся с существующего сайта. Переписывать интерфейс или запускать Python на телефоне не нужно.

## Как открыть в Android Studio

1. Полностью распакуйте скачанный ZIP через **«Извлечь всё»**. Не открывайте проект прямо внутри архива.
2. В Android Studio выберите **File → Open**. В новом интерфейсе File находится под кнопкой ☰ слева сверху.
3. Выберите папку **`LEXIAndroid`**. В общем архиве сайта она находится внутри `android/LEXIAndroid`, а в отдельном Android-архиве — прямо после распаковки. Внутри неё находятся `settings.gradle.kts`, `gradlew.bat`, `gradle` и `app`. Подпапку `app` и корень веб-проекта выбирать не нужно.
4. Если Android Studio предложит довериться проекту и установить недостающий **Android SDK 35**, подтвердите установку. Дождитесь завершения **Gradle Sync**. Первый запуск скачивает инструменты и зависимости.
5. Сверху должна появиться конфигурация **app**. Выберите Android-телефон или эмулятор и нажмите зелёный **Run ▶**.

Созданный ранее проект `LEXIAPP` можно оставить рядом. Этот проект уже содержит настроенные файлы: вручную вставлять веб-архив в `MainActivity.kt` не требуется. Внутренний идентификатор — **`com.ada.lexi`**, название на телефоне — **LEXI**.

Для сборки нужен JDK **17 или 21**. Обычно подходит встроенный JDK Android Studio: **Settings → Build, Execution, Deployment → Build Tools → Gradle → Gradle JDK**. Пакеты Python, Neon и отдельный сервер на компьютере для этой Android-сборки не нужны.

## Первый запуск

- Подключитесь к интернету. Для первого открытия нужен работающий сайт на Render. Если сервер долго запускается, дождитесь страницы; при ошибке нажмите «Попробовать ещё раз».
- Войдите в существующий аккаунт LEXI. Вход браузера и вход внутри Android — отдельные сессии, поэтому пароль вводится один раз и в приложении. После входа приходит прогресс аккаунта с сервера.
- В гостевом режиме действуют правила сайта: прогресс временный и очищается после завершения посещения/перезагрузки. Для сохранения используйте аккаунт.
- Фото выбирается через системный выбор файла; доступ ко всей галерее приложению не выдаётся.
- Озвучивание использует системный Text-to-Speech. Если Android сообщает, что английский голос недоступен, установите английский голос в настройках озвучивания устройства. На эмуляторе голос может отсутствовать.
- Share открывает системное меню «Поделиться». Export предлагает выбрать, куда сохранить JSON с учебным прогрессом.
- Кнопка Android «Назад» сначала обрабатывает открытый диалог сайта, затем возвращает предыдущий экран; с первого экрана закрывает приложение.

## Что это за версия

Это **онлайн-оболочка существующего сайта**. Регистрация, вход, фото и синхронизация используют тот же сервер и его базу. Новая база или аккаунты не создаются автоматически самим Android-проектом. Изменения сайта будут доступны и в приложении.

Отдельная автономная база Room пока не добавлена. Офлайн-кеш и восстановление аккаунта зависят от существующей логики сайта и поддержки Service Worker установленным Android System WebView; первый вход и работа с сервером требуют интернета. Возможность полностью автономной работы будет отдельным этапом.

## Где менять адрес и название

- Адрес и разрешённый хост: `app/src/main/java/com/ada/lexi/SitePolicy.kt`.
- Проверка адреса адаптером: первая строка проверки `location.origin` в `app/src/main/assets/lexi-android.js`. При смене домена обновите оба файла.
- Название на телефоне: `android:label` в `app/src/main/AndroidManifest.xml`.
- Авторизация и база остаются в веб-проекте. Пароль подключения к базе не добавляется в Android-код.

Внутри WebView разрешён только свой HTTPS-хост. Ссылки на словари, почту и телефон открываются через приложения Android. HTTP, произвольные файловые адреса и обход ошибок сертификата не включены. Отладочный инспектор WebView работает только в debug-сборке; WebView-данные исключены из облачного резервного копирования и переноса устройства.

## Проверка разработчиком

```sh
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

На Windows вместо `./gradlew` используйте `gradlew.bat`. Отладочный APK появится в `app/build/outputs/apk/debug/app-debug.apk`. Ключ debug создаётся на компьютере разработчика и не входит в репозиторий. Для публикации нужна отдельная подписанная release-сборка.

В корневом репозитории также есть браузерная проверка адаптера:

```sh
python android/LEXIAndroid/tests/adapter_browser.py
```

Она использует Playwright/Chromium и настоящий модуль хранения LEXI, перехватывает все запросы и не создаёт аккаунты на реальном сервере. Зависимости этой проверки не нужны для сборки приложения.
