# Открыть LEXI в Android Studio

Откройте **File → Open → папка `LEXIAndroid` рядом с этим файлом**.

Это отдельный готовый Android-проект с подключённым сайтом `https://lexi-m388.onrender.com/`. Файл `MainActivity.kt` уже заполнен. Веб-интерфейс сохранён.

[Пошаговая инструкция](LEXIAndroid/README.md).

[Скачать отдельный ZIP Android-проекта](LEXIAndroid.zip). В нём только исходники Android и Gradle Wrapper, без базы сайта, SDK, ключей подписи и готовых APK.
