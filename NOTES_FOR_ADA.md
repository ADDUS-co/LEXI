# Заметки для Ады: как работать с LEXI

Для изменения слова не нужно заново создавать сайт. Сделай маленькое изменение, сохрани, проверь, а потом опубликуй.

## 1. Первый запуск на Windows

1. Установи Python 3.12 или новее с python.org. В установщике включи **Add Python to PATH**.
2. Скачай ZIP проекта. Нажми по нему правой кнопкой → **Извлечь все / Extract All**. Не запускай проект прямо внутри ZIP.
3. В VS Code выбери **File → Open Folder** и папку с `app.py`.
4. Выбери **Terminal → New Terminal**. Терминал — окно для команд; он должен быть открыт в папке проекта.
5. Выполни команды по одной:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

6. Открой `http://localhost:5000` в браузере и выбери интересы.
7. Остановка сервера: **Ctrl+C** в терминале.
8. При следующем запуске достаточно последней команды: среду создавать заново не надо.

**Небольшой словарь:**

- Python — язык серверной части.
- Flask — Python-библиотека, которая отвечает на запросы браузера.
- `venv` — отдельная среда с инструментами для этого проекта. Ее папка называется `.venv`; ее не отправляют в GitHub.
- `__pycache__` — временные файлы Python. Их не редактируют и не публикуют.
- Терминал выполняет введенные команды. Браузер показывает результат работы сайта.
- `localhost` — твой компьютер. Это не публичная ссылка в интернете.
- API — адрес, по которому JavaScript получает данные от Flask, например `/api/catalog`.

**Go Live не подходит:** он показывает статические файлы, но не запускает Flask и API. Не открывай `templates/index.html` двойным щелчком. Используй команду запуска выше.

Команды работают без активации среды, поэтому менять PowerShell ExecutionPolicy не нужно. Если VS Code просит интерпретатор: **Ctrl+Shift+P → Python: Select Interpreter → `.venv\Scripts\python.exe`**.

## 2. Как добавить английское слово

1. Открой папку LEXI в VS Code.
2. Слева открой **data → words.json**.
3. Это список записей между `[` и `]`. Каждое слово — объект между `{` и `}`.
4. Найди конец последнего объекта. Поставь после него запятую и вставь новую запись до закрывающей `]`.
5. Полный пример для копирования:

```json
{
  "id": "law-mediation",
  "collectionId": "law",
  "word": "Mediation",
  "partOfSpeech": "noun",
  "ipa": "/ˌmiː.diˈeɪ.ʃən/",
  "shortDefinition": "A process in which a neutral person helps others try to reach an agreement.",
  "fullDefinition": "Mediation is a process in which a neutral third party helps people discuss a dispute and seek an agreement. The mediator helps the conversation rather than imposing a decision. The process and its legal effects depend on the context and jurisdiction.",
  "simpleExplanation": "Two sides disagree. A neutral person helps them talk and look for a solution they can both accept.",
  "synonyms": [
    {
      "word": "facilitation",
      "definition": "Helping a group communicate or work together; it need not involve a dispute."
    }
  ],
  "examples": [
    "Both sides agreed to try mediation.",
    "Mediation helped them discuss their concerns calmly."
  ],
  "relatedWords": [
    {
      "word": "mediator",
      "definition": "A neutral person who helps parties try to resolve a dispute."
    }
  ],
  "usageNote": "A mediator helps the parties seek agreement; an arbitrator is generally asked to make a decision.",
  "difficulty": "C1",
  "source": {
    "label": "Wiktionary · further reading",
    "url": "https://en.wiktionary.org/wiki/mediation#English"
  }
}
```

| Поле | Что писать |
| --- | --- |
| `id` | Уникальное постоянное имя записи: `law-mediation`. Используй маленькие латинские буквы и дефис. Не повторяй ID другого слова. |
| `collectionId` | ID существующей коллекции. Связывает слово с интересом. |
| `word` | Английское слово для отображения. |
| `partOfSpeech` | Часть речи: `noun`, `verb`, `adjective` и т. п. |
| `ipa` | Транскрипция IPA. Проверь по надежному словарю, не угадывай. |
| `shortDefinition` | Короткое точное значение для первого экрана. |
| `fullDefinition` | Более полное объяснение для нижней части страницы. |
| `simpleExplanation` | Та же мысль простым английским. |
| `synonyms` | Близкие слова: `word` — слово, `definition` — доступное объяснение и отличие. Можно оставить `[]`. |
| `examples` | Один или несколько проверенных примеров. Пустым быть не должен. |
| `relatedWords` | Связанные слова с пояснениями. Можно оставить `[]`. |
| `usageNote` | Необязательное замечание об употреблении. |
| `difficulty` | Необязательный ориентировочный уровень. Это не результат экзамена. |
| `source` | Необязательная ссылка HTTPS для чтения: `label` — подпись, `url` — адрес. |

Основные ID коллекций: `law`, `travel`, `technology`, `business`, `lifestyle`.

**Правила JSON:**

- Текст пишется в двойных кавычках `"`.
- Между полями и соседними объектами ставится запятая.
- Перед закрывающей `]` или `}` последней запятой быть не должно.
- Списки используют `[]`, объекты — `{}`.
- Кавычки внутри текста записываются как `\"`: `"She said \"hello\"."`.
- Комментарии `//` в JSON запрещены.
- Сохраняй файл в UTF-8: это важно для транскрипций и русского текста.

6. Нажми **Ctrl+S**.
7. Проверь проект:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -p "test_*.py" -v
```

8. Обнови страницу. Количество слов видно в Collections; данные доступны на `http://localhost:5000/api/catalog`.
9. Новое слово не обязательно станет сегодняшним: календарь выбирает одну запись автоматически. Добавление слов меняет длину цикла и может изменить сегодняшнюю запись.

Для JSON перезапуск обычно не нужен. При изменении Python останови сервер и запусти снова. Перед добавлением проверяй значения, IPA и примеры. Сайт не создает определения с помощью AI при запуске.

## 3. Как добавить коллекцию

Например, Medicine:

1. Открой `data/collections.json`.
2. Добавь объект в конец списка с запятой после предыдущего:

```json
{
  "id": "medicine",
  "name": "Medicine",
  "description": "Words for understanding health, care, and the human body.",
  "icon": "sun"
}
```

3. В `words.json` добавь минимум одно полное слово с `"collectionId": "medicine"` и новым ID, например `medicine-diagnosis`. Значение проверь по надежному источнику.
4. Сохрани оба файла и запусти проверки. Коллекция появится в onboarding и Collections без изменения Python, HTML или CSS.

Таким же способом добавляются Psychology (`psychology`), Literature (`literature`), Science (`science`), Architecture (`architecture`). ID — внутреннее имя без пробелов; `name` — видимая подпись.

Готовые значки: `scales`, `compass`, `chip`, `chart`, `sun`, `spark`. Новый рисунок можно позже добавить в `static/js/icons.js`, но для коллекции это необязательно. Не оставляй пустую коллекцию: проверка требует хотя бы одно слово.

## 4. Как изменить слово

В `words.json` нажми **Ctrl+F** и найди слово или его ID. Измени определение или пример, нажми **Ctrl+S**. Сохраняй прежний ID: по нему Saved и History узнают запись.

Обнови браузер. Сохраненное слово можно открыть в Saved. Прямая ссылка имеет вид `http://localhost:5000/#word/law-precedent`: замени последнюю часть на нужный ID. Открытое слово действительно попадет в историю.

## 5. Как безопасно удалить слово

1. Сделай копию файла или Git-коммит.
2. Удали весь объект слова от `{` до соответствующей `}`.
3. Исправь запятую между соседями: двух запятых подряд и запятой перед `]` быть не должно.
4. Убедись, что в коллекции осталось хотя бы одно слово.
5. Сохрани и запусти проверки.

При следующей загрузке сайта отсутствующий ID будет убран из локальных Saved/History. Старая ссылка покажет понятное сообщение. Удаление влияет на календарь. При удалении коллекции сначала удали или перенеси ее слова: не оставляй неверные collectionId.

## 6. Как менять дизайн

Открой `static/css/style.css`. В начале — переменные трех тем.

| Переменная | Что меняет |
| --- | --- |
| `--bg` | Общий фон |
| `--surface` | Фон расширенного объяснения |
| `--panel` | Небольшие панели |
| `--text` | Основной текст |
| `--muted` | Базовый дополнительный оттенок палитры |
| `--muted-readable` | Читаемый цвет мелких подписей: в Studio он темнее для контраста |
| `--accent-text` | Акцент для текста, отдельно от фона кнопок |
| `--accent` | Акцентные кнопки, линии и выделения |
| `--word-color` | Главное английское слово |
| `--border` | Границы |
| `--page-gutter` | Боковые поля |
| `--section-space` | Вертикальные отступы секций |
| `--transition` | Длительность смены цветов |

Пример: в `[data-theme=studio]` замени `--word-color: #536633;` на `--word-color: #455c2b;`. Не приближай текст к цвету фона; проверь читаемость.

Размер слова находится в `.hero-word`, заголовков — `.page-heading h1`. `clamp()` задает минимальный, гибкий и максимальный размер. Правила телефонов находятся в блоках `@media`, анимации — рядом с `@keyframes`. Не удаляй `prefers-reduced-motion`: эта настройка помогает людям, которым движение мешает.

Нажми Ctrl+S и обнови страницу. Если виден старый CSS, попробуй **Ctrl+F5** при подключении к сети. Офлайн может показываться последняя кешированная версия.

## 7. Как менять контакты

Все контакты находятся в **`data/site.json`**, в `contacts`.

- Instagram: измени видимый `text` и `url` вида `https://www.instagram.com/.../`.
- Telegram: `text` и `https://t.me/...`.
- Телефон: `text` может содержать пробелы; `url` записывается как `tel:+77058733464`.
- Почта: `url` имеет вид `mailto:ardaksok@mail.ru`.

`label` — название контакта, `icon` — значок. Чтобы скрыть один контакт, удали его объект и исправь запятые. Чтобы скрыть все: `"contacts": []`. Не публикуй данные, которые не хочешь показывать посетителям.

## 8. День, история и сохранение

Часовой пояс — **Бишкек, UTC+6**. Одинаковые интересы и дата дают одинаковое слово. Тема на это не влияет. Дата проверяется примерно каждые 30 секунд и при возвращении на вкладку.

Алгоритм берет первое слово из каждой выбранной коллекции, затем вторые и так далее. Номер дня с 1 января 2025 года выбирает позицию в этом списке. В одном круге слова не повторяются. Когда список заканчивается, круг начинается заново. Изменение интересов или базы меняет результат. Технические правила: `docs/SELECTION.md`.

Saved содержит только явно сохраненные слова. History — реально открытые слова с датами, без будущей базы. Одно слово записывается один раз за дату просмотра.

`localStorage` — память сайта в твоем браузере. На другом телефоне или в другом браузере будет отдельная история. После очистки данных сайта записи исчезнут. В Settings есть экспорт JSON для личного архива и сброс с подтверждением. Автоматического импорта и синхронизации пока нет.

## 9. Как публиковать изменения

Путь: **VS Code → локальные проверки → GitHub → Render → обновленный сайт**.

Используй существующий репозиторий LEXI или создай свой. Не загружай `.venv`, `__pycache__`, `.env`: они добавлены в `.gitignore`.

Если Git настроен, а папка уже является клоном:

```sh
git status
git add app.py lexi data templates static requirements.txt render.yaml README.md NOTES_FOR_ADA.md docs tests .gitignore .env.example
git commit -m "Update LEXI vocabulary and interface"
git push
```

Перед добавлением просмотри `git status`. Не включай посторонние файлы и секреты. GitHub-авторизация компьютера настраивается отдельно; токены нельзя записывать в исходники.

Без команд Git: открой репозиторий на GitHub → **Add file → Upload files**, загрузи файлы с сохранением папок и нажми **Commit changes**. Для небольшой правки можно открыть файл, нажать карандаш и сохранить коммитом. Локальная проверка перед публикацией все равно полезна.

### Первый запуск на Render

1. В Render выбери **New → Web Service** и подключи GitHub-репозиторий.
2. Runtime: **Python 3**.
3. Build Command: `pip install -r requirements.txt`.
4. Start Command: `gunicorn app:app --bind 0.0.0.0:$PORT --workers 2 --timeout 60`.
5. Health Check Path: `/health`.
6. В Environment добавь `LEXI_TIMEZONE` = `Asia/Bishkek`. Секреты для MVP не нужны.
7. Нажми **Create Web Service**. Альтернатива: **New → Blueprint** с `render.yaml`.
8. Дождись успешного деплоя и проверь выданный HTTPS-адрес с телефона.

Gunicorn работает в Linux на Render; для Windows-разработки нужен только `python app.py`. Не включай Flask debugger в интернете. Бесплатный Render может засыпать и медленно просыпаться; актуальные условия смотри в Render.

После `git push` Render обычно автоматически запускает деплой, если Auto-Deploy включен. Дождись завершения. Ctrl+S на твоем компьютере само по себе публичный сайт не меняет.

### Как отменить ошибочную публикацию

Сначала найди ошибочный коммит. Можно создать отменяющий: `git revert НОМЕР_КОММИТА`, затем `git push`. Не используй `reset --hard` или force push без понимания последствий. В Render также можно выбрать предыдущий успешный deploy → **Rollback**. Исправь и GitHub, иначе следующий автодеплой может вернуть ошибку.

## 10. Частые проблемы

| Проблема | Как исправить |
| --- | --- |
| `No module named flask` | Установи зависимости через `.\.venv\Scripts\python.exe -m pip install -r requirements.txt`; запускай тем же Python. |
| Python / `py` не найден | Установи Python с Add to PATH, открой новый терминал. Если работает `python --version`, используй `python` вместо `py -3`. |
| `Address already in use` | Останови свой старый сервер Ctrl+C. Либо в PowerShell задай `$env:PORT="5001"`, запусти снова и открой localhost:5001. |
| Invalid JSON | Проверь кавычки и запятые. Выполни `.\.venv\Scripts\python.exe -m json.tool data/words.json`, затем unit-тесты для проверки ID и коллекций. |
| CSS не обновился | Ctrl+S, подключение к сети, Ctrl+F5. При необходимости DevTools → Application → Service Workers → Unregister, затем обновление. |
| Неверный Python в VS Code | Ctrl+Shift+P → Python: Select Interpreter → Python из `.venv`. |
| Render deployment failure | Открой Logs. Проверь requirements.txt, app.py, папки lexi/data и команды запуска. Исправь конкретную ошибку и сделай Redeploy. |
| Ноутбук работает, телефон нет | На телефоне localhost означает сам телефон. Используй HTTPS-адрес Render. В одной Wi-Fi-сети можно тестировать `http://IP-ноутбука:5000`, если Firewall разрешает; сервер слушает 0.0.0.0. Не открывай порт роутера в интернет. |
| Missing static files | Проверь папку static и регистр имен. На Render регистр важен. Запускай Flask, не HTML напрямую. Не используй пути C:\... в веб-адресах. |
| Пустой или сломанный словарь | Нужен непустой массив, уникальные ID, существующие collectionId и минимум одно слово в каждой коллекции. Проверь /health, тесты и серверный журнал. |
| Не работает произношение | Проверь установленный английский голос или другой браузер. Звук создает устройство; IPA остается доступной. |
| Не устанавливается PWA | Для публичного сайта нужен HTTPS; localhost подходит для разработки. После онлайн-открытия проверь меню браузера. Обычный HTTP по IP в Wi-Fi может не поддерживать Service Worker. |
| Пропало избранное | Возможно, изменился браузер, адрес/порт или очищены данные. Каждый origin имеет свое localStorage; синхронизации нет. |

## 11. Дальше: Android

Сначала проверь сайт на настоящих устройствах. Потом можно создать отдельный проект Kotlin в Android Studio. Для виджета подходит Jetpack Glance: слово, IPA, короткое значение, коллекция и переход в LEXI по нажатию.

Используй те же JSON и алгоритм из `docs/SELECTION.md`. PWA-иконка на домашнем экране — не нативный виджет. Android-приложение в этом проекте пока не создается.
